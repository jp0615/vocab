單字小達人 PWA（純靜態，無需建置）
檔案：index.html、manifest.json、sw.js、icon-192/512.png、apple-touch-icon.png
本機測試：python3 -m http.server 8000 ，開 http://localhost:8000
部署：上傳整個資料夾到 GitHub Pages / Cloudflare Pages / Netlify（需 HTTPS，離線與加入主畫面才完整）。
iPad：Safari 開網址 → 分享 → 加入主畫面。第一次開啟連網一次，之後可離線。
換 iPad：家長區→「匯出／匯入」下載 JSON 或複製代碼，在另一台匯入。
